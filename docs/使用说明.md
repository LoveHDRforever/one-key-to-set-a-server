# 使用说明 · onekeytosetaserver **0.2.6**

> **这一版加了两件事、改了一件事**：
> ① **商店支持 NBT** —— 附魔书、药水这类"同名不同货"的物品可以**单独上架、单独定价**，买到的就是那一件；
> ② **售卖区**：把**任意物品**放进箱子界面，点「确认出售」、3 秒内再点一次，就自动识别哪些能卖、卖掉，
> **不能卖的原样退回**（顺带补上了这个界面一直缺的游戏内入口 `/sell`）；
> ③ **盔甲 / 武器 / 工具 / 原矿方块 / 刷怪蛋永久禁止交易** —— 商店和自由市场都不能买、不能卖，
> 升级时这些商品会从价目表里自动删掉（**157 件**），市场上还挂着的会被撤下并邮寄回卖家。
> 0.2.5 及以前的全部内容都保留，完整说明看 **`总说明书_0.2.6_zh_CN.md`**。

## 一、商店支持 NBT（0.2.6 新增）

### 玩家侧：没什么新操作

* 在商店里点开附魔书/药水，看到的就是**那一本/那一瓶**，买下来带附魔、带效果；
* 卖的时候只认"一模一样"的那一种：**附魔不同、药水不同、名字不同都算不同的货**；
* 唯一的例外是**耐久磨损**：用旧的工具（如果服主上架过）和新的算同一种 —— 比较时会忽略 `Damage`（磨损）和
  `RepairCost`（铁砧惩罚）。

### 服主侧：`/shop edit` 就是"NBT 价目表编辑器"

```
1) 手持那件带 NBT 的物品（比如一本经验修补附魔书）
2) /shop edit          # 预览格会显示「附魔 经验修补 I」，并标注「这条只对带同样 NBT 的物品生效」
3) 调买价 / 回收价 → 保存
```

> 手持**普通物品**（无 NBT）设价，改的是"这种物品的通配价"——**任何 NBT 都按这个价收/卖**，
> 这也是 0.2.5 及以前所有条目的行为，老价目表升级后语义完全不变。

想手改文件、或者想看手上物品的 NBT 长什么样：

```
/shop nbt              # op3：打印 NBT 摘要（附魔/药水/名字/模型/耐久）+ 完整 SNBT，可直接复制到 json
```

### 价目表结构（`multiverse/shop/recycle.json`）

**0.2.6 起是数组**，老的 `{"id": 价格}` 对象会在第一次启动时**自动迁移**（并留 `recycle.json.bak`）：

```json
[
  { "itemId": "minecraft:stone", "price": 0.18 },                                  ← 通配：任何石头（含带 NBT 的）都收
  { "itemId": "minecraft:enchanted_book",
    "nbt": "{StoredEnchantments:[{id:\"minecraft:mending\",lvl:1s}]}",
    "price": 300.0 }                                                               ← 精确：只有"经验修补 I"这本收 300
]
```

* **`nbt` 不写 = 通配**（任何 NBT 都按这个价）；**写了 = 精确**（必须一致）；
* 同一种物品同时有通配和精确条目时，**精确优先**；
* `categories.json` 里的商品同理：`items[]` 多了一个可选字段 `nbt`，不写就是普通物品。

## 二、售卖区：`/sell`

### 三个入口

| 入口 | 说明 |
|---|---|
| `/sell` | 直接打开 |
| 商店分类页 **46 号槽** | 按钮叫「售卖区（卖任意物品）」 |
| 主菜单 **24 号槽** | 默认主菜单里叫「售卖区（卖任意物品）」（老 `menus.json` 里可能还是 `sellall`，把参数改成 `sell` 即可） |

### 流程（4 步）

1. 打开界面，把**想卖的任意物品**放进上面 45 格（Shift 点击可以从背包快速搬进来；放错了 Shift 点击搬回去）；
2. 底部 **45 号**实时显示：**可卖几件、共多少钱、几件不可卖**；
3. 点 **49 号「确认出售」**——**第一次点不会卖**，只会变金色并提示"再点一次"；
4. **3 秒内再点一次** → 结算：能卖的按回收价**入账**，不能卖的**原样退回背包**（背包满则掉在脚下），
   聊天栏告诉你"结算了几件、拿了多少钱、退回几件"。

### 三条硬规则

* **没点第二次 = 一件都不卖**：直接关界面、按 Esc，物品**全部退回**，不会因为手滑丢东西；
* **只卖你放进来的**：界面是独立容器，**不会动你背包里其它的东西**（和 `/sellall` 的区别就在这里）；
* **不可卖的一定退回**：没有回收价的物品（比如被永久禁交易的东西）不会被吞掉，结算时整组退回。

### 和 `/sellall` 的区别

| | `/sell` 售卖区 | `/sellall` |
|---|---|---|
| 卖什么 | **你放进界面的** | 主背包 36 格里**所有**有回收价的 |
| 确认 | **要点两次** | 一次执行（菜单里的按钮会自动加"再点一次"） |
| 盔甲/副手/饰品 | 不碰 | **不碰**（0.2.6 修好：以前实际会连身上盔甲、副手一起卖） |

## 三、永久禁交易（0.2.6 新增，改不动）

| 家族 | 包含 | 判定 |
|---|---|---|
| 盔甲 | 头盔/胸甲/护腿/靴子、鞘翅、海龟壳、各种马铠 | 原版 `ArmorItem` / `HorseArmorItem` |
| 武器 | 剑、弓、弩、三叉戟、盾牌 | `SwordItem` / 弓类 / `TridentItem` / `ShieldItem` |
| 工具 | 镐、斧、锹、锄、剪刀、钓鱼竿、打火石、刷子、胡萝卜钓竿 | `DiggerItem` 等 |
| 原矿方块 | 煤/铁/金/钻石/绿宝石/青金石/红石/铜/下界金/下界石英及其深板岩变种 | id 以 `_ore` 结尾 |
| 刷怪蛋 | 全部 | `SpawnEggItem` |

* **商店**：升级时从价目表删掉（157 件），**买不到也卖不掉**；刷怪蛋分类整类消失。
* **自由市场**：上架、购买都拒绝；**已经在售的**在启动时撤下并**邮寄回卖家**（`/mail` 领）。
* **黑名单也不管用**：这是**代码写死的规则**，`/market blacklist add` 加不了、`remove` 也解不开，
  `blacklist.json` 里不会出现它们。
* **故意没禁**：粗铁/粗金/粗铜、远古残骸、各种锭/宝石、箭矢 —— 只有"矿石方块"被禁。
  要连粗矿/残骸一起禁，说一声，改一行就行。
* 装了别的 mod（拔刀剑、枪械、神化…）时，它们的剑/镐/盔甲只要继承了原版对应类，**同样被拦**。

## 五、升级步骤（0.2.5 → 0.2.6）

1. **停服**（用 `/stop`，不要强杀），备份 `multiverse/` 整个目录（尤其是 `multiverse/shop/`）；
2. 服务端：删 `mods/onekeytosetaserver-0.2.5.jar`，放入 **`mods/onekeytosetaserver-0.2.6.jar`**；
3. 客户端：`oktsas_chatbridge-0.2.5.jar` 换成 **`oktsas_chatbridge-0.2.6.jar`**；
   主 mod jar 若也在客户端，**一起换成 0.2.6**；
4. **启动**，第一次会自动做三件事（日志里能看到）：
   * `[Shop] recycle.json upgraded to the NBT aware list format (a copy of the old file is at recycle.json.bak)`
   * `[Shop] table upgraded to 0.2.6: banned families removed, books/potions category ... added where missing`
   * `[Market] took down N listing(s) of banned items and mailed them back to their sellers`（有老挂单才有）
   * `[Shop] 11 categor(ies), 833 item(s), 814 recycle price(s) (0 with NBT rules)`
5. 快速验证：

```
/shop list                     # 应显示 11 个分类 / 833 件
/sell                          # 应打开售卖区界面，底部 45 号显示"可卖 0 件"
/shop nbt                      # 手持任意物品，应打印它的 NBT 摘要（普通物品显示"没有 NBT"）
```

> **老数据不用手改**：`categories.json` 里你加过的商品会保留（除非属于上面五类禁交易），
> `recycle.json` 自动转数组、老的纯 id 行语义不变（= 通配价）；
> 其它文件（世界、背包池、领地、市场、菜单、邮箱）**格式全部没变**。

## 六、四个需要知道的边界

1. **售卖区界面里的物品在"没确认"时是内存里的**：正常关界面会退回，只有**服务器崩溃/强杀**时，
   界面里还没确认的物品才会丢（和原版箱子一样）。别在售卖区界面里囤货。
2. **NBT 不匹配 = 不可卖**：卖一本"耐久 III"的书，而回收表里只有"经验修补 I"的精确价、
   又没有附魔书通配价时，这本书会被当成"不可卖"退回。想做"整类同价"，就再加一条不带 `nbt` 的通配价。
3. **通配价会盖住"同名不同货"的差别**：只要 `recycle.json` 里有一条 `minecraft:enchanted_book` 通配价，
   任何附魔书都按那个价收 —— 想按附魔区分，就删掉通配价、只留精确条目。
4. **永久禁交易不是"配置"**：它写在代码里，改配置文件、加黑名单、换 `blacklist.json` 都不会解除。
   真要放开某一类，得改代码发新版（说一声就行）。
